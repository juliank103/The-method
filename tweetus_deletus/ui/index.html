One-time setup

X only lets apps delete posts through its official API, so this needs an X developer app. Whoever sets Tweetus Deletus up does this once. If someone set it up for you, ask them for the Client ID and skip to step 2.

  1. 1

    Create your X developer app

    X only allows bulk deleting through its official API, so you need your own app. You only do this once, and it takes about five minutes.

    1. Open the X Developer Portal and sign in with the account you want to clean up.
    2. Create a Project and an App. Any name is fine, for example “My cleanup”.
    3. In the app, find User authentication settings and click Set up:
      • App permissions: Read and write and Direct message
      • Type of App: Native App
      • Callback URI:
      • Website URL: any site, for example https://example.com
    4. Save, then copy the OAuth 2.0 Client ID it shows you.

    X bills API use on pay-per-use plans, so add credits in the portal if it asks. Searching your downloaded archive uses almost none.
